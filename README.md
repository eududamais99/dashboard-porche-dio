# 🚗 Dashboard Porsche Sales

## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante o desafio da DIO com o objetivo de criar uma dashboard interativa em HTML utilizando Inteligência Artificial para transformar uma planilha de vendas da Porsche em informações visuais úteis para tomada de decisão.

A dashboard foi publicada utilizando GitHub Pages e permite explorar os dados através de filtros dinâmicos.

---

## 🎯 Perguntas de Negócio

### 1. Qual modelo gerou a maior receita?

Essa análise permite identificar quais veículos tiveram maior impacto financeiro nas vendas.

### 2. Como as vendas evoluíram ao longo dos anos?

Permite acompanhar tendências de crescimento ou redução das vendas.

### 3. Qual método de pagamento é o mais utilizado?

Ajuda a compreender o comportamento dos clientes durante a compra.

---

## 🧹 Tratamento dos Dados

Antes da criação da dashboard, foram realizados os seguintes ajustes:

* Utilização apenas das colunas sanitizadas;
* Conversão dos campos de preço e ano para formato numérico;
* Remoção de fórmulas, mantendo apenas os valores;
* Organização da base para leitura pela IA.

---

## 🤖 Utilização de IA

A dashboard foi construída utilizando o ChatGPT para geração do código HTML, CSS e JavaScript.

Durante o desenvolvimento, o prompt foi refinado para:

* adicionar filtros;
* melhorar a aparência visual;
* incluir indicadores (KPIs);
* tornar os gráficos responsivos;
* corrigir erros encontrados durante os testes.
